# Love Nails kz — Концептуальная ногтевая студия в Астане

Премиальный сайт ногтевой студии **Love Nails kz** (г. Астана, пр. Сарыарка, 17), разработанный в эстетике Tilda Zero Block / high-fashion editorial.

## Особенности проекта
- **Адаптивный дизайн**: полностью оптимизирован для смартфонов (iOS / Android) и широкоформатных экранов.
- **Подлинные материалы**: используются исключительно реальные фотографии студии, интерьера и авторских работ Love Nails kz из официальной галереи 2GIS и Instagram.
- **Интерактивный прайс-лист**: актуальные цены и категории (Маникюр, Smart-педикюр, Наращивание и моделирование ногтей) с быстрым поиском и фильтрацией.
- **Онлайн-запись в Altegio**: бесшовные ссылки на запись ко всем мастерам (Айзара, Молдiр, Шамира, Айым, Дильназ).
- **Высокая производительность**: чистый HTML5, CSS3 (Custom Properties, Flexbox, CSS Grid) и Vanilla JavaScript без тяжелых внешних библиотек.

## Локальный запуск
Просто откройте файл `index.html` в любом современном браузере.
